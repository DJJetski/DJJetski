# Datenschutz: Google-App „DJ Jetski Agenten“

„DJ Jetski Agenten“ ist eine private Google-OAuth-App von DJ Jetski. Sie gibt
seinen eigenen lokalen Werkzeugen Zugriff auf seine eigenen Google-Tabellen und
-Dateien, zum Beispiel für die Buchhaltung.

- **Wer sie nutzt:** nur DJ Jetski selbst, mit seinem eigenen Google-Konto. Die
  App ist für niemanden sonst gedacht.
- **Welche Daten:** Tabellen und Dateien in seinem eigenen Google-Konto, nur
  wenn er selbst oder seine lokalen Werkzeuge sie lesen oder schreiben.
- **Speicherung:** Zugangsdaten und Inhalte bleiben auf seinem eigenen Rechner.
  Nichts wird verkauft, an Dritte weitergegeben oder für Werbung genutzt.
- **Google-Richtlinie:** Die Nutzung von Daten aus Google-APIs hält sich an die
  [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)
  einschließlich der Limited-Use-Anforderungen.
- **Widerruf:** Der Zugriff lässt sich jederzeit unter
  [myaccount.google.com/permissions](https://myaccount.google.com/permissions)
  entfernen.
- **Kontakt:** über [github.com/DJJetski](https://github.com/DJJetski).

## Privacy (English)

"DJ Jetski Agenten" is a private Google OAuth app used only by DJ Jetski with
his own Google account. It lets his own local tools read and write his own
Google Sheets and Drive files. Credentials and data stay on his own computer;
nothing is sold, shared with third parties or used for advertising. Use of data
from Google APIs follows the Google API Services User Data Policy, including
the Limited Use requirements. Access can be removed at any time at
myaccount.google.com/permissions.
